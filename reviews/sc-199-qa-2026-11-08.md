## Non-blocking findings

- **[doc] "same cell" is really the rounding basin.** `01/INV-2`, AC-4 and the
  glossary define a cell as the 10^-n grid square; round-to-nearest cannot satisfy
  that literally. Counterexample: 43.68291 and 43.68299 are both in
  [43.6829, 43.6830) but snap to 43.6829 and 43.6830. Reword to "within
  +/-0.5 x 10^-n of a snapped value".
- **[pre-existing] REST accepts a non-finite radius.** `radius=Infinity` and
  `radius=1e308` return 200 with all 30 rows; the MCP tool rejects non-finite
  (`radiusMiles must be a finite number`, SC-209 `48ad3f0`). Radius handling was
  declared unchanged for SC-199; worth a follow-up for parity/cost.
- **[edge] late 500 keeps the public directive.** A route that sets the policy and
  then throws yields `Cache-Control: public, max-age=60, no-store` (two values,
  public first). RFC 9111 no-store wins, so not storable; noted for Omar.
- **[traceability] docs drift.** 10-traceability says PR #84 (actual #85), uses
  label-style test names, and 09 WI-7 cites `OpenApiDocumentTest` which does not
  exist anywhere in the repo (no OpenAPI drift guard). The frontend vendored
  `src/lib/api/openapi.json` / `schema.d.ts` were not refreshed (description-only,
  no type change). OpenAPI text says "4 decimal places" even when configured to 3.
- **[test gap] wiring not asserted.** No test proves `config.search.centrePrecision`
  reaches `SearchListingsForAgent` (AppModules.kt:198) or `config.search` reaches
  `listingRoutes` (Application.kt:109). A hardcoded-4dp regression would stay green.
- **[evidence] INV-8 now has a measurement** (delta above); traceability can stop
  calling it an unasserted residual.
